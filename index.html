Sobre o Projeto

O Snake Game é um projeto desenvolvido utilizando a linguagem de programação Python e a biblioteca Pygame. O objetivo é recriar o clássico jogo da cobrinha, proporcionando uma experiência simples, divertida e desafiadora.

Durante o desenvolvimento, são aplicados conceitos importantes de programação, como estruturas de repetição, condicionais, funções, eventos do teclado, colisões, movimentação de objetos e controle de pontuação.

Funcionalidades

🐍

Movimentação

Controle a cobra utilizando as teclas direcionais do teclado.

🍎

Comida

Colete os alimentos para aumentar o tamanho da cobra e sua pontuação.

🏆

Pontuação

Quanto mais alimentos forem coletados, maior será a pontuação.

💥

Colisões

Evite bater nas paredes e no próprio corpo da cobra.
